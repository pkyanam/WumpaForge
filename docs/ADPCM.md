# Native Xbox ADPCM buffers

`patches/xboxrecomp-audio.patch` now includes the native SDL/CoreAudio output,
producer cadence fixes, standalone Xbox ADPCM decoder and DirectSound buffer
implementation. The source is in the ignored xboxrecomp checkout; bootstrap applies
this patch. No supplied game data is included in the test fixtures.

## Format and ownership

Xbox ADPCM tag 0x69 contains 36 bytes per channel and exactly 64 PCM frames per
block, including the initial predictor. Stereo stores two four-byte headers,
then alternates four-byte channel groups. The final high nibble is unused.
The decoder validates complete blocks, header indices/reserved bytes and output
capacity before writing. It produces interleaved signed 16-bit PCM without allocation.

The native buffer backend accepts PCM16 and Xbox ADPCM, mono/stereo, with validated
block size. For ADPCM the samples-per-block extension is WORD at byte 18, value 64.
Buffer objects own copied encoded data and decoded PCM; PCM16 shares its raw storage.
Replacing malformed data preserves the old buffer/playback. Unsupported formats
return DSERR_BADFORMAT. No whole-disc decoding or allocation is performed.

Creation reserves metadata only. Play obtains one of 64 reserved mixer slots;
Stop/release return it, and completed playback is reclaimed on queries or when
allocation needs a slot. Thus 252 idle title buffers do not exhaust voices.
The 65th simultaneously playing buffer returns DSERR_ALLOCATED. Cursors map ADPCM
block byte offsets to 64-frame boundaries. Lock stops playback before exposing
owned bytes and Unlock re-decodes. Only linear locks with flags zero are supported.

## Primary-source golden fixture

The numeric fixtures were generated by compiling the original Xbox decoder from
[vgmstream revision 09c9f40caae4747e44b6a993b3d5b654cef4d1f7](https://github.com/vgmstream/vgmstream/blob/09c9f40caae4747e44b6a993b3d5b654cef4d1f7/src/coding/ima_decoder.c).
`tools/generate_adpcm_fixture.py` extracts its unchanged IMA tables, expansion
routine and Xbox decoding function into a tiny adapter, and feeds synthetic mono
and stereo blocks. The resulting `tools/fixtures/xbox_adpcm_golden.h` covers
predictor clipping, index transitions, channel grouping and multiple blocks.
The decoder uses the reference shift/add rounding. FFmpeg's Xbox decoder also
confirms 64 frames with a skipped trailing nibble, but its multiply rounding is
not the bit-exact oracle used here.

Regenerate with `python3 tools/generate_adpcm_fixture.py` (selective source download,
small compile). Run the standalone decoder with sanitizers:

```sh
clang -std=c11 -O1 -g -fsanitize=address,undefined -fno-omit-frame-pointer tools/test_xbox_adpcm.c third_party/xboxrecomp/src/audio/xbox_adpcm.c -o build/test_xbox_adpcm_asan
./build/test_xbox_adpcm_asan
```

The broader buffer test uses the current platform static library from the native
build and a dummy SDL device:

```sh
clang -std=c11 -O1 -g -Ithird_party/xboxrecomp/src -Ithird_party/xboxrecomp/src/apu -Ithird_party/xboxrecomp/src/nv2a $(pkg-config --cflags sdl2) tools/test_dsound.c third_party/xboxrecomp/src/audio/xbox_adpcm.c third_party/xboxrecomp/src/apu/apu_core.c third_party/xboxrecomp/src/apu/apu_vp.c third_party/xboxrecomp/src/apu/apu_dsp.c third_party/xboxrecomp/src/apu/apu_xaudio2.c build/native/third_party/xboxrecomp/src/platform/libplatform.a $(pkg-config --libs sdl2) -o build/test_dsound
./build/test_dsound
```

Both tests passed on this ARM64 Mac on 2026-09-08. The broader test verifies 252
idle objects, 64 simultaneous voices, real producer completion/reclaim, PCM and
ADPCM data, cursor mapping, re-decode, atomic malformed replacement and cleanup.
A full buffer test with AddressSanitizer could not run: SDL2-compat opened its
SDL3-load error dialog before main. A process sample confirmed the initializer
stack; the owned process was terminated. Decoder-only ASan/UBSan passed.

## Remaining integration

The game has not reached native audio calls yet. The guest ABI bridge remains
separate work described in [AUDIO-INTEGRATION.md](AUDIO-INTEGRATION.md). Output
streams and play regions return E_NOTIMPL. Existing native 3D methods and DSP
pipeline still contain incomplete behavior; do not expose them as successful
spatial/effects support. A native stream needs a real bounded packet queue and
completion accounting. These tests establish buffer decoding/playback mechanics,
not working game music or spatial sound.
