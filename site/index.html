An experimental native Mac project

WumpaForge

Build Crash Bandicoot: The Wrath of Cortex as a native Apple Silicon Mac app from your own USA original Xbox disc image.

Original game code is statically recompiled to ARM64, with native graphics, audio and input compatibility.

Build your appExplore the source

Requires Apple Silicon and macOS 14 or newer. No game files are included.

Experimental status: Arctic Antics was completed on an M3 MacBook Air. Other levels, story effects, and hardware configurations still need testing.
Your copy, your Mac

Build locally from your own disc

The guided setup checks a supported, unmodified USA Xbox ISO, prepares the build tools, recompiles the game code and packages a personal app on your Mac.

Run setup

Use the one-line installer or download the source and run setup.sh. Review the scripts first if you prefer.

Select your ISO

Choose your original USA Xbox disc image when prompted. It stays unchanged and is never uploaded.

Build and play

Setup creates build/WumpaForge.app. Keyboard and supported SDL controller mappings are available.

Know before you build

Early, measured progress

One level completed

Arctic Antics was completed using keyboard controls on an M3 MacBook Air. That is not validation of the full game.

Not a performance promise

60 FPS is a target, not a guarantee. Upscaling changes output presentation; it does not add original scene detail.

More testing needed

Story visual artifacts, untested levels and routes, physical controller pairing, and broader host validation remain open.

See the current status and changelog for details.
